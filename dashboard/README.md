# Dashboard Module

## Generated dashboard

`product_sales_dashboard.html` is generated by the build script and can be opened in a browser. It is a self-contained interactive dashboard; detailed tables stay in the generated CSV files under `../outputs`.

It contains:

- Business question, main finding, business implication and recommendation.
- Executive KPIs: revenue, merchandise products, orders, Top 500 revenue share and forecast error.
- Product explorer with search, action-group filter, rank metric selector and Top N control.
- Product drill-down panel with revenue, units, orders, customer reach, active months and recommended action.
- Product comparison panel for side-by-side revenue, unit and reach comparison.
- Forecast and validation panel with product-level forecast, MAE, MAPE and validation interpretation.
- Geographic sales context with domestic/international filtering.
- Data quality status across six dimensions.

The repository homepage also includes static SVG versions of the key visuals so that the business story is visible directly on GitHub without opening the HTML file. The HTML dashboard adds interaction for reviewer exploration.

## Power BI version

For a Power BI version, import these files from `../outputs`:

- `product_performance.csv`
- `order_purchase_summary.csv`
- `product_revenue_concentration.csv`
- `top_products_by_revenue.csv`
- `top_products_by_quantity.csv`
- `slow_moving_product_candidates.csv`
- `product_quarterly_sales.csv`
- `product_next_quarter_forecast.csv`
- `product_forecast_backtest.csv`
- `country_sales_context.csv`
- `monthly_kpis.csv`
- `customer_profile_summary.csv`
- `purchase_behavior_summary.csv`
- `data_quality_checks.csv`

Recommended pages:

1. Overview - revenue, orders, products, countries and product concentration.
2. Customer and Purchases - repeat status, orders per customer, order value and basket size.
3. Product Leaders - Top products by revenue and units sold.
4. Catalogue Health - active months, low-revenue products and slow-moving candidates.
5. Geographic Sales Context - domestic/international split and country/region concentration.
6. Forecast - next-quarter baseline and backtest error for stable high-revenue products.
7. Data Quality - quality checks and cleaning assumptions.

## Suggested visuals

- KPI cards for revenue, orders, stock codes and merchandise products.
- Distribution charts for repeat status, orders per customer, order value and units per order.
- Bar charts for Top 10 revenue and Top 10 quantity products.
- Concentration chart for Top 10/50/100/500 revenue share.
- Bar chart for slow-moving product candidates.
- Forecast bar chart for stable high-revenue products.
- Forecast validation chart using MAE, MAPE and bias.
- Country/region revenue map or ranked bar chart.
