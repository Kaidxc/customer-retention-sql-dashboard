# Data Dictionary

## Input fields

| Field | Definition |
|---|---|
| `invoice_no` | Invoice identifier. One invoice can contain multiple product lines. |
| `stock_code` | Product or service/admin stock identifier. |
| `description` | Product description from the transaction record. |
| `quantity` | Number of units on the transaction line. |
| `invoice_date` | Transaction timestamp. |
| `unit_price` | Unit price in GBP. |
| `customer_id` | Customer identifier. Used for purchase reach and behaviour context, not demographic profiling. |
| `country` | Customer country or region. |
| `source_period` | Source worksheet period from the original dataset. |
| `line_value` | Transaction-line value, calculated as `quantity * unit_price`. |

## Product-level metrics

| Metric | Definition |
|---|---|
| `product_description` | Primary description used for a stock code in the generated product outputs. |
| `stock_line_type` | `merchandise` or `service_or_admin_line`. Service/admin lines include postage, manual adjustments, bank charges and carriage. |
| `total_quantity` | Total units sold for a product. |
| `total_revenue` | Total sales value for a product. |
| `order_count` | Number of distinct invoices containing the product. |
| `customer_count` | Number of distinct known customers who bought the product. |
| `average_selling_price` | Product revenue divided by quantity sold. |
| `active_months` | Number of months in which the product recorded sales. |
| `first_sale_date` | Earliest sale date for the product. |
| `last_sale_date` | Latest sale date for the product. |
| `days_since_last_sale` | Difference between the analysis date and the product's last sale date. |
| `quantity_rank` | Product rank by units sold. |
| `revenue_rank` | Product rank by revenue. |

## Product planning outputs

| Metric | Definition |
|---|---|
| `product_group` | Revenue concentration group such as Top 10, Top 50, Top 100 or Top 500. |
| `products_in_group` | Number of products in the concentration group. |
| `group_revenue` | Revenue generated by the concentration group. |
| `revenue_share` | Group revenue divided by total merchandise revenue. |
| `feature` | Product feature being summarised in `product_catalog_summary.csv`, such as active months, revenue or days since last sale. |
| `bucket` | Distribution bucket used in summary outputs. |
| `product_share` | Products in a bucket divided by all merchandise products. |
| `sale_quarter` | Calendar quarter used for product-level quarterly sales. |
| `quantity_sold` | Units sold by product and quarter. |
| `forecast_quantity` | Next-quarter unit baseline for a selected stable product. |
| `forecast_revenue` | Next-quarter revenue baseline for a selected stable product. |
| `latest_quarter_quantity` | Units sold in the latest observed quarter for the forecasted product. |
| `latest_quarter_revenue` | Revenue in the latest observed quarter for the forecasted product. |
| `method` | Forecasting method used for the baseline. |

## Data quality fields

| Metric | Definition |
|---|---|
| `dimension` | Data quality dimension, such as accuracy, validity or completeness. |
| `check_name` | Specific quality check performed. |
| `affected_rows` | Number of rows affected by the check. |
| `affected_share` | Affected rows divided by total clean transaction rows. |
| `status` | `Pass` or `Review`. |

## Supporting customer-behaviour metrics

These fields are retained as supporting context because the dataset contains `customer_id`, but they are not used as demographic customer features.

| Metric | Definition |
|---|---|
| `total_orders` | Count of distinct invoices per customer. |
| `average_order_value` | Total revenue divided by distinct orders. |
| `first_purchase_date` | Earliest order date for a customer. |
| `last_purchase_date` | Latest order date for a customer. |
| `days_since_last_purchase` | Difference between analysis date and last purchase date. |
| `repeat_customer_flag` | 1 if a customer has at least two orders, otherwise 0. |
| `recency_score` | Behaviour score where 5 means most recent. |
| `frequency_score` | Behaviour score where 5 means most frequent. |
| `monetary_score` | Behaviour score where 5 means highest revenue. |
