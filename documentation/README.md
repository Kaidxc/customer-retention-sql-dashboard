# Documentation Module

This folder explains the project context and how to present it in job applications.

## Files

| File | Purpose |
|---|---|
| `business_brief.md` | Business problem, stakeholder and decision supported |
| `data_dictionary.md` | Field definitions and metric definitions |
| `analysis_notes.md` | Key modelling choices and limitations |
| `data_quality_checks.md` | Data quality dimensions, generated checks and interpretation |
| `evaluation_plan.md` | Treatment/control plan for measuring whether the recommended action works |
| `forecasting_extension.md` | Short-term forecasting baseline, method and limitations |
| `skills_demonstrated.md` | Application-ready mapping from project evidence to analyst skills |
| `cv_project_bullets.md` | CV-ready project wording |
