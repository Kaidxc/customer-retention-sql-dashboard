# Documentation Module

This folder explains the project context and how to present it in job applications.

## Files

| File | Purpose |
|---|---|
| `business_brief.md` | Business problem, stakeholder and decision supported |
| `data_dictionary.md` | Field definitions and metric definitions |
| `analysis_notes.md` | Product analysis choices, classification logic and limitations |
| `data_quality_checks.md` | Data quality dimensions, generated checks and interpretation |
| `insight_to_action.md` | Mapping from findings to recommended actions, monitoring metrics and extra data needs |
| `evaluation_plan.md` | Plan for measuring product actions such as stock protection, bundling and slow-moving review |
| `forecasting_extension.md` | Product-level next-quarter baseline, backtest method and limitations |
| `skills_demonstrated.md` | Application-ready mapping from project evidence to analyst skills |
| `cv_project_bullets.md` | CV-ready project wording |

Related BI documentation is in [`../power_bi/`](../power_bi/).
