# CV Project Bullets

## Short CV version

Online Retail Product Sales & Demand Analysis

- Built a SQL-driven product sales analysis using 793k cleaned Online Retail II transaction lines, covering 36,969 orders and GBP 17.7m in revenue.
- Created product, order, country and forecast-validation outputs for revenue, units, order reach, customer reach, basket size, geographic context, product concentration and slow-moving review.
- Developed a business-facing GitHub report with visual evidence for product range, purchase behaviour, country/region sales context, Top products, slow-moving products and next-quarter planning.
- Built and backtested a transparent next-quarter baseline for stable high-revenue products using quarterly sales history.
- Documented a Power BI-ready data model, DAX/KPI definitions, data quality checks, assumptions, limitations and evaluation plans for technical and non-technical reviewers.

## Analyst role version

Online Retail Product Sales & Demand Analysis

- Transformed order-line retail data into product-level decision tables using SQL, Python and pandas.
- Analysed product performance and purchase behaviour across revenue, quantity, order reach, customer reach, basket size and active selling months to separate revenue drivers from volume drivers.
- Identified a broad product range with many low-selling items, country/region sales concentration and slow-moving products with meaningful historical revenue but weak recent sales.
- Produced dashboard-ready CSVs, SVG charts, a visual-first HTML dashboard and a narrative GitHub README written as a business report.
- Designed a Power BI reporting layer with star schema, DAX/KPI definitions and page-by-page dashboard plan.
- Framed practical product actions for stock protection, bundling, slow-moving review and demand planning, with forecast backtesting and a proposed evaluation approach.
