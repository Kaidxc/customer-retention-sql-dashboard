# Outputs Module

This folder contains dashboard-ready outputs generated by:

```bash
python scripts/build_online_retail_outputs.py
```

## Main product outputs

| File | Description |
|---|---|
| `dataset_overview.csv` | Overall dataset size, revenue, date range and analysis date |
| `order_purchase_summary.csv` | One row per invoice with order value, units purchased, product lines and distinct products |
| `product_performance.csv` | Product-level units, revenue, orders, customers, selling price, active months and ranks |
| `product_revenue_concentration.csv` | Revenue share for Top 10, Top 50, Top 100 and Top 500 merchandise products |
| `product_catalog_summary.csv` | Bucketed product distributions for active months, revenue and days since last sale |
| `country_sales_context.csv` | Country/region revenue, orders, customers, units and domestic/international grouping |
| `top_products_by_revenue.csv` | Top 10 merchandise products by revenue |
| `top_products_by_quantity.csv` | Top 10 merchandise products by units sold |
| `slow_moving_product_candidates.csv` | Merchandise products with historical revenue but no sale for at least 180 days |
| `product_quarterly_sales.csv` | Product-by-quarter quantity, revenue, orders and customer reach |
| `product_next_quarter_forecast.csv` | Next-quarter baseline for stable high-revenue merchandise products |
| `product_forecast_backtest.csv` | Historical validation of the four-quarter product forecast baseline |
| `monthly_kpis.csv` | Monthly revenue, orders, customers, AOV and repeat-purchase context |
| `purchase_behavior_summary.csv` | Bucketed order-value, units-per-order and distinct-products-per-order distributions |
| `data_quality_checks.csv` | Generated checks for accuracy, validity, timeliness, completeness, consistency and uniqueness |
| `executive_summary.md` | Generated product sales and demand summary |
| `portfolio_metrics.json` | Compact metrics used by the generated dashboard |

## Supporting customer-behaviour outputs

These are retained as supporting context only. The dataset contains customer IDs but no demographic customer attributes.

| File | Description |
|---|---|
| `customer_metrics.csv` | One row per customer with purchase-frequency, revenue and recency metrics |
| `customer_profile_summary.csv` | Bucketed customer purchase-behaviour distributions |
| `repeat_customer_summary.csv` | Customers with at least two completed orders |

## Dashboard use

The product CSVs can be loaded into Power BI, Tableau, Excel, or a notebook. The recommended dashboard pages are documented in `../dashboard/README.md` and the Power BI data model is documented in `../power_bi/`.
